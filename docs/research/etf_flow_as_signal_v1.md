# ETF Flow as Signal — 量能增强方向参考

> 本文档不构成实验计划。仅记录 ETF 净申赎作为量能强度候选增强指标的分析，
> 供未来回测基线建立后决定是否纳入。

## 核心思路

成交额相关指标（`amount_ratio`、`sector_amount_share`）反映的是**买卖成交的总量**，
无法区分资金流入还是流出方向。ETF 净申赎提供了一个补充视角：

> **ETF 总份额增加 → 一级市场净申购 → AP 需买入一篮子成分股 → 真实的资金流入对应行业**

与行业指数的成交额不同，ETF 申赎记录的是**机构资金的真实配置行为**。

## 数据源：tushare `etf_share_size`

| 属性 | 说明 |
|------|------|
| 接口 | `etf_share_size` |
| 覆盖 | **沪深全市场 + 北交所**（非仅深市） |
| 频率 | **日频**，每日 19:00 后更新 |
| 关键字段 | `total_share`（总份额万份）、`total_size`（总规模万元）、`nav`（净值） |
| 获取成本 | 8000 tushare 积分 |
| 计算净申赎 | `net_flow(万元) = (total_share(t) - total_share(t-1)) × nav(t)` |

比 `rt_etf_sz_iopv`（上一个接口）好在哪：
- 覆盖 SH+SZ+BSE，而不仅是 SZ
- 日频直接可用，不需要聚合日内数据
- 数据稳定，每日收盘后固定更新

## 与现有量能指标的关系

| 指标 | 反映什么 | 使用场景 | 建议 |
|------|---------|---------|------|
| `amount_ratio` (额比) | 行业自身的放量/缩量状态 | 量价配合确认 | ✅ 已写入 DB |
| `sector_amount_share` | 全市场成交额集中度变化 | 资金是否集中到某行业 | ⏳ 回测时实时算 |
| ETF净申赎 | 机构资金对该行业的配置方向 | 确认/背离信号 | 📝 v1 暂不做 |

最有价值的信号模式：**背离**
- 行业指数还在涨 + 行业 ETF 连续净赎回 → 机构在借涨出货
- 行业指数还在跌 + 行业 ETF 连续净申购 → 聪明钱在抄底

## 局限性与注意事项

1. **ETF 跟踪误差**：行业 ETF 的持仓不完全等于申万一级行业，可能跨行业
2. **非全行业覆盖**：不是每个申万行业都有对应的主流 ETF
   - 覆盖较好的：电子/半导体、食品饮料/酒、银行、券商、医药、新能源
   - 覆盖较差的：综合、轻工制造、纺织服饰等
3. **净值 vs 价格**：ETF 净申赎是从一级市场的申购/赎回行为推导，不同于二级市场的买入/卖出
4. **数据成本**：8000 积分在 tushare 体系下需要积累一定调用量
5. **信号滞后**：净申赎数据于每日 19:00 后放出，对盘中决策无帮助，适合日频回测

## 未来接入方向

如果在回测基线建立后决定纳入：

1. 用 `etf_share_size` 拉取全部行业 ETF 的每日份额数据
2. 建立 ETF-to-sector 映射表（手工标记每只 ETF 对应的申万行业）
3. 按行业聚合净申赎信号（可能一只行业对应多只 ETF）
4. 在回测中作为副信号检查：该行业 RS 信号是否伴随 ETF 净流入或净流出
5. 可决定是否持久化到 `market_daily_data`（需要新增字段）

## 与资金净流入（大单拆分）的对比

| | 大单净流入（东方财富/同花顺） | ETF净申赎（`etf_share_size`） |
|---|---|---|
| 数据性质 | 按成交额阈值推算，非事实 | 交易所公布的份额变化事实 |
| 各平台一致性 | 差——阈值不同结论打架 | 好——以 tushare 为统一源 |
| 信号含义 | "猜测大资金方向" | "机构资金真实进出" |
| 覆盖全面性 | 全市场 | 仅限有 ETF 的行业 |
| 成本 | 东方财富 API 收费，akshare 可用但限速 | 8000 tushare 积分 |
| 推荐度 | ❌ 不推荐 | ⚠️ 建议 v2 考虑 |
