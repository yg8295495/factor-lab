## 三、当日快照（需日频积累才有历史序列）

以下接口返回当日实时快照，**无历史序列**。如需使用需要每天跑一次采集，日积月累形成时间序列。

| 接口 | 字段 | 当前数据量 |
|------|------|-----------|
| `stock_rank_cxfl_ths()` | 持续放量个股（含所属行业） | 当日快照 ~122条 |
| `stock_rank_cxsl_ths()` | 持续缩量个股（含所属行业） | 当日快照 ~853条 |
| `stock_hot_rank_em()` | 人气排行 | 当日快照 ~100条 |

**用途**：聚合到行业级别，可作为行业量价异常信号。
**注意**：同花顺源，本机可通 ✅。但需要日频积累才能做序列分析。

## 四、数据更新策略

### 4.1 核心日频（每日更新）

```
CSI指数（25个）:  stock_zh_index_hist_csindex(code, 19900101, 今日)
申万行业（30个）:  index_hist_sw(code)
创业板指（1个）:   stock_zh_index_daily + stock_zh_index_daily_tx 合并
```

建议运行时间：每日收盘后 18:00（数据更新后）

### 4.2 补充数据（可选，按需）

```
北向资金: 每日/每周更新
融资余额: 每周更新
全市场资金流: 每日更新（仅120天）
人气排行: 当日快照（无历史）
```

### 4.3 一键更新脚本

```bash
python factor-lab/backend/rebuild_db.py     # 全量重建（清空+重拉）
```

## 六、知识库（移植到 macOS 时参考）

### 6.1 Python 环境

```
# 需要安装的包
pip install akshare baostock sqlalchemy pandas numpy scipy
pip install playwright              # 仅当需要东财 push2his 数据时
playwright install chromium         # 装 Playwright 浏览器
```

macOS 上无需处理 Clash/代理问题，东财 `push2` 大概率可直连。

### 6.2 Git 管理

```
factor-lab/
├── .gitignore 应包含:
│   data/quant_engine.db     # 数据库文件不提交
│   __pycache__/
│   .DS_Store
│
├── 建议提交:
│   docs/                    # 全部文档
│   backend/                 # 全部代码
│   README.md / PLAN.md      # 项目文档
```

首次克隆后执行 `python backend/rebuild_db.py` 重建数据库。

### 6.3 数据来源总结（一句话记牢）

```
25指数 → CSI接口(有PE)   30行业 → 申万接口(字段全)   创业板 → Daily+腾讯合并
CR5 → 本地SQL计算         大宗交易 → 可选采集         北向资金 → 已失效
东财push2 → 本机不通      持续放量缩量 → 当日快照需日频积累
```
