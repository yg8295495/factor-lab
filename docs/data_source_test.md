# 数据源测试清单

> 在 factor-lab/ 目录下执行，确认每个接口的通断状态。
> 测试完成后，把结果（✅/❌/⚠️）填入状态列。

---

## 1. 宽基指数日线（东方财富）

```bash
python -c "
import akshare as ak
codes = ['000001','000300','000905','000852','000688','399006','000016','000985','000510']
for c in codes:
    try:
        df = ak.index_zh_a_hist(symbol=c)
        print(f'✅ {c}: {len(df)} 行, {df.iloc[0][\"日期\"]} ~ {df.iloc[-1][\"日期\"]}')
    except Exception as e:
        print(f'❌ {c}: {e}')
"
```
