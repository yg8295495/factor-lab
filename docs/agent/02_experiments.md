# 实验方向与结论

## 总体目标

基于因子 → 行业评分的轮动策略，寻找行业切换的先行信号。

## 方法论

- 分阶段用窗口回看行业行为（W1/W2/W3 三段式）
- 循环版滚动回测，每 20 天调仓
- 超额收益 vs 中证全指（index.000985.CSI）

## 已完成

### v1 行业评分（已废弃）
```
方法: 单点阳线率+RS排名+成交量+持续性
结果: 命中率 8.3%，天然偏向防御板块
结论: 单点评分无法捕捉行业切换信号
```
